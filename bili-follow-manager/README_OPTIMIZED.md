# B站关注管理助手：保守增强优化版

## 这版改了什么

1. `injected.js`
   - 给 WBI key 增加 Promise 锁，避免并发分析时多个请求同时穿透到 `/x/web-interface/nav`。
   - 增加接口冷却器。遇到 HTTP 412/429 或返回 `-412/-429` 时，后续请求先短暂等待，不继续密集请求。
   - 保留原有 MD5/WBI 签名逻辑和所有指令路由，避免大面积重写导致不可控问题。

2. `content.js`
   - 默认参数改为更稳妥的低频配置：分析并发 3、基础间隔 300ms、取关间隔 1200ms、单批取关 30。
   - 修复读取关注列表时重复清理 `processedUnfollowMids` 和 `unfollowRecords` 的问题。
   - 增加特别关注双保险：既读关注列表里的 `special` 字段，也额外读特别关注接口并放入 `specialMids` 集合。
   - 投稿查询增加随机抖动、限速识别、最多 3 次退避重试；遇到明确限速/风控码会自动停止，避免继续请求。
   - 表格渲染改为 `DocumentFragment` 一次性挂载，默认最多展示 800 条，减少 DOM 卡顿。
   - 新增“反选当前列表”按钮，批量筛选时更方便。

3. `panel.css`
   - 给表格行增加 `content-visibility: auto`，大列表滚动更流畅。
   - 给表格小字加省略处理，长标题/长原因不再撑爆界面。

## 安装步骤

### Chrome / Edge

1. 解压 `bili-follow-manager-optimized.zip`。
2. 打开浏览器扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的文件夹：`bili-follow-manager-clean`。
6. 打开或刷新任意 B站页面，右下角应出现“B管”按钮。

## 推荐使用顺序

1. 先登录 B站账号，并打开任意 `https://www.bilibili.com/` 页面。
2. 点击右下角“B管”。
3. 点击 `0. 自检登录/接口`。
4. 点击 `1. 读取关注列表`。
5. 点击 `2. 分析最近投稿`。
6. 先 `导出 CSV` 人工核对。
7. 确认无误后，可以点击 `创建/应用唯一自动分组`。
8. 需要取关时：先筛选、勾选，再在确认框输入 `确认取关`，最后点击 `取关已勾选`。

## 推荐参数

稳妥模式：

- 分析并发：`3`
- 单请求间隔 / ms：`300`
- 分组操作批量：`50`
- 分组操作间隔 / ms：`800`
- 取关每次最多：`30`
- 取关间隔 / ms：`1200`

如果出现限速、验证码、412、-352、-412 等提示：停止操作，隔一段时间再继续，不要马上提高并发。

## 验证指令

在源码目录执行：

```bash
node --check injected.js
node --check content.js
```

如果两条命令都没有输出错误，说明 JavaScript 语法检查通过。
