# B站关注管理助手 修复版 v2

本版修复两个你截图里暴露的问题：

1. **读取完成但表格为空**：读取关注列表后，即使还没有点击“分析最近投稿”，表格也会显示已读取的关注账号，状态为“未分析”。
2. **旧参数 50/100/200 被继续带入**：旧版参数保存在浏览器 storage/localStorage 中，新代码会读取旧 key，所以看起来默认值没变。本版更换为新的参数 key `bfmParamsSafeV2`，默认使用更稳的安全参数。

## 安全默认参数

- 长期未更新阈值：90 天
- 关注时间超过：180 天才列为候选
- 最多分析数量：0，即全部
- 分析并发：3
- 单请求间隔：300 ms，并自动加入随机抖动
- 分组操作批量：50
- 分组操作间隔：800 ms
- 取关每次最多：30
- 取关间隔：1200 ms

## 安装

1. 解压 zip。
2. 打开 `chrome://extensions/` 或 `edge://extensions/`。
3. 打开开发者模式。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 `bili-follow-manager-clean` 文件夹。
6. 刷新 B站页面。

## 使用顺序

1. 自检登录/接口。
2. 读取关注列表。
3. 此时表格应该已经显示 3858 这类关注账号，状态为“未分析”。
4. 再点击分析最近投稿。
5. 导出 CSV 核对。
6. 确认后再分组或取关。

如果页面还是显示旧参数，请在扩展页面先“移除”旧扩展，再重新加载这个 v2 文件夹，或者刷新 B站页面两次。
