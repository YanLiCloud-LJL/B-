# B站关注管理助手

这是一个 Chrome / Edge 浏览器扩展，用于辅助管理 B站关注列表。

功能包括：

- 自检登录状态、csrf 与接口连通性。
- 读取当前账号的全部关注列表。
- 分析关注账号最近投稿时间。
- 根据“最近投稿状态”或“内容类型”给每个 UP 生成唯一自动分组。
- 保护特别关注账号，不会被批量取关。
- 导出 CSV / JSON 报告。
- 批量取关候选账号，取关成功后会立即从列表和已选集合中移除，下一批不会重复处理。
- 参数每次点击任务按钮时都会重新读取，界面输入值会立即生效。
- 参数保存采用安全存储：优先使用扩展 storage，不可用时自动回退到 localStorage，避免 chrome.storage.local 报错。

## 一、安装方法

### Edge

在地址栏打开：

```text
edge://extensions/
```

### Chrome

在地址栏打开：

```text
chrome://extensions/
```

然后按以下步骤操作：

```text
1. 开启“开发人员模式”。
2. 删除旧的同类测试插件，避免多个内容脚本同时运行。
3. 解压本插件压缩包。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后的 bili-follow-manager-clean 文件夹。
6. 打开 https://www.bilibili.com/ 并确认已登录。
7. 刷新 B站页面。
8. 点击右下角“B管”按钮。
```

PowerShell 解压示例：

```powershell
cd D:\download
Expand-Archive -Force .\bili-follow-manager-clean.zip .\bili-follow-manager-clean
```

## 二、推荐使用顺序

```text
0. 自检登录/接口
1. 读取关注列表
2. 设置参数
3. 分析最近投稿
4. 创建/应用唯一自动分组
5. 导出 CSV 或 JSON 核对
6. 勾选候选
7. 输入：确认取关
8. 点击：取关已勾选
```

注意：不要同时安装多个旧版本插件。多个插件同时注入页面，会造成按钮、列表和日志互相干扰。

## 三、参数说明

### 长期未更新阈值 / 天

用于判断一个 UP 是否属于“近期未更”。例如设置为 90，表示最近 90 天内没有投稿，就会被认为近期未更。

### 关注时间超过 / 天才列为候选

用于避免误伤刚关注的账号。例如设置为 180，表示只有关注超过 180 天，并且满足未更新条件时，才列入取关候选。

### 最多分析数量，0=全部

用于限制分析数量。

```text
0：分析全部关注用户。
500：只分析前 500 个关注用户。
```

### 分析并发

同时请求最近投稿接口的数量。并发越高越快，但越容易触发接口限制。

### 单请求间隔 / ms

分析最近投稿时，每个请求之间的间隔。

### 分组操作批量

每次向 B站分组接口提交的账号数量。

### 分组操作间隔 / ms

每批分组操作之间的间隔。

### 取关每次最多

每次点击“取关已勾选”时最多处理多少个账号。

例如你勾选了 500 个，设置为 100，则第一次点击处理 100 个。成功取关的账号会从列表里实时移除，第二次点击会自动继续处理剩余 400 个。

### 取关间隔 / ms

每个账号取关请求之间的间隔。

### 调试日志

开启后会在控制台输出更多运行信息，便于排查问题。

## 四、唯一自动分组规则

每个 UP 只会进入一个自动分组，不会同时进入多个自动分组。

优先级如下：

```text
疑似异常
> 无公开投稿
> 一年未更
> 半年未更
> 近期未更
> 内容分类
```

可能创建的自动分组：

```text
自动疑似异常
自动无公开投稿
自动一年未更
自动半年未更
自动近期未更
自动知识科技
自动动漫游戏
自动音乐娱乐
自动生活日常
自动影视剪辑
自动其他活跃
```

活跃账号会进入内容分类；不活跃账号优先进入未更新类分组。

---

## 五、特别关注保护

特别关注账号会被强制保护。

即使你手动勾选了特别关注账号，取关时也会自动跳过，不会取消关注。

## 七、常见问题

### 出现 Cannot read properties of undefined (reading 'local')

这个包已经规避该问题：参数保存会优先使用扩展 storage，不可用时自动回退 localStorage。若你仍然看到该错误，通常是旧插件内容脚本还留在当前页面里。请删除旧插件后刷新 B站页面。

### 取关成功后列表没有消失

这个包会在取关成功后同步移除以下数据：

```text
已选集合
候选列表
分析结果
关注列表
表格显示
统计数字
```

再次点击“取关已勾选”时，只会继续处理剩余账号。

### 出现 -352

这是接口风控。请停止操作，等待一段时间后再降低并发、增加间隔。

### 分组提示 22105

说明该账号当前关系不允许直接加入分组，例如悄悄关注或非公开关系。插件会跳过，不会强制改变你的隐私关注状态。
